# B.I.G.O.D.E — site

Esta pasta é o **site** (HTML, CSS e JavaScript). Os dados ficam no Google Planilhas.

- `index.html` — página
- `css/style.css` — visual
- `js/app.js` — lógica do sistema
- `js/data.js` — funções e equipamentos de cada termo
- `js/sheets-config.js` — **link do Apps Script** (único arquivo que você edita para ligar a planilha)
- `js/sheets-shim.js` — conexão com a planilha e tela de entrada

Não há dados de colaboradores nesta pasta, por isso ela pode ir para o GitHub.
Veja o `PASSO-A-PASSO.md` na pasta acima.
